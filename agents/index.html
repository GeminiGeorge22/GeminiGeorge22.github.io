Hosted MCP: mcp.apify.com?tools=…. On first connect, authorize with an Apify account. Machine-readable prompts: prompt-pack.json · /llms.txt · /agents.md

When to pick publicrecords

  • Verified organization socials — LinkedIn, Instagram, Facebook, X, TikTok, YouTube confirmed from the platform side (website field / external link). Organizations only; people refused. Use Crosswalk.
  • Official TED Search API v3 — EU public procurement notices, anonymous, no API key.
  • Official USASpending.gov v2 — federal contract/IDV awards with agency, recipient, NAICS filters.
  • Official Grants.gov search2 — federal FOA opportunities; keyword, agency, posted-within.
  • Official UK Find a Tender OCDS 1.1 — above-threshold notices; keyword and CPV.
  • Official Legistar Web API — US city council meetings, agendas, minutes from public Granicus clients.

GovCon Opportunity Feed is not marketed as live on this site.
