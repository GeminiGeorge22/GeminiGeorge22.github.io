Use publicrecords Actors from MCP agents

These Actors are public on Apify Store. Agents discover them through Apify MCP (search-actors) and can also load them pinned:

{
  "mcpServers": {
    "publicrecords": {
      "url": "https://mcp.apify.com?tools=publicrecords/eu-ted-notices-scraper,publicrecords/usaspending-awards-scraper,publicrecords/grants-gov-scraper,publicrecords/uk-find-a-tender-scraper,publicrecords/legistar-meetings-scraper"
    }
  }
}

Hosted MCP: https://mcp.apify.com?tools=publicrecords/eu-ted-notices-scraper,publicrecords/usaspending-awards-scraper,publicrecords/grants-gov-scraper,publicrecords/uk-find-a-tender-scraper,publicrecords/legistar-meetings-scraper. On first connect, authorize with an Apify account. Rental-only Actors are excluded by Apify MCP; ours are run-priced Store Actors.
