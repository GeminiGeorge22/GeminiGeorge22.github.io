PDF to Text & Markdown Extractor: OCR, DOCX, RAG chunks

Give it links to PDF or Word (.docx) files. It returns each document as clean Markdown text, reads scanned pages with OCR, and splits the text into chunks ready for a vector database or an LLM prompt.

Open PDF to Text & Markdown Extractor on Apify →

The one question it answers

What is the clean Markdown text of these PDF or Word files, with scanned pages read by OCR and the text split into RAG-ready chunks?

Who it is for

Teams building RAG search or chatbots over PDFs, reports, papers and contracts; AI agents that need the text of a PDF or DOCX link as Markdown; anyone who needs PDF to text in bulk without a separate OCR or AI API.

Input

FieldWhat to putDefault
documentUrlsDirect links to PDF or Word (.docx) files. Up to 50 MB per file.Store example: an arXiv PDF and a scanned PDF
ocrModeauto (scanned pages only), always, or offauto
ocrLanguageLanguage of the scanned text (English, French, German, Spanish, and others)eng
chunkSize / chunkOverlapToken size and overlap for RAG chunks. 0 turns chunking off.400 / 40
pageRangeOnly convert these PDF pages, e.g. 1-5,8 or 10-lastevery page up to the page limit

Output

One dataset row per document (or one row per chunk if you turn on One row per chunk), with markdown, chunks (heading path, offsets, token estimate), page counts, and which pages were read with OCR. Pay per event on your own Apify account (free tier available). Current rates are on the Store page. No outside OCR or AI API is called.

PDF and DOCX only (no .doc, images or spreadsheets). Password-protected PDFs are skipped with a reason. Handwriting is not supported. This tool is not affiliated with arXiv or OCRmyPDF; those links appear only in the Store example input.

Try it in 1 minute

  1. Open the Store page and run the example input (a text PDF and a scanned PDF, OCR on Auto).
  2. Or pin it in an MCP client: mcp.apify.com?tools=publicrecords/pdf-docx-to-markdown and sign in with your Apify account.
  3. Or import the n8n workflow or the Make HTTP recipe. Set your own Apify token; do not commit it.
