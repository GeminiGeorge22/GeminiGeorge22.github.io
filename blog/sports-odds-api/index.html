How to pull sports odds from BetRivers, Unibet, Paf, Svenska Spel and ATG

A short path for sports bettors and developers who want one row per game, with each book's price and the best price per outcome. Author: Public Records (I maintain the Actor).

What you get

The Sports Odds API reads live and pre-game odds from BetRivers (12 US states + Ontario), Unibet (7 countries), Paf, Svenska Spel and ATG. It does not cover DraftKings or FanDuel.

1. Run the Store example

On the Store page, keep the example input (NBA, NFL, NHL, MLB, Premier League; maxEvents 10) and start a run on your Apify account. The free tier is enough to try it. Pay per game after that.

2. Or pin it in MCP

Paste https://mcp.apify.com?tools=publicrecords/sports-odds-api into Claude, Cursor, or another MCP client and sign in with your own Apify account.

3. Or schedule it in n8n or Make

Import templates/n8n/sports-odds-api.json (Workflows → Import from file) and add a Header Auth credential Authorization: Bearer <APIFY_TOKEN>. The Make HTTP recipe is in templates/make. Use your token; never commit it.

POST https://api.apify.com/v2/acts/publicrecords~sports-odds-api/run-sync-get-dataset-items
Authorization: Bearer <APIFY_TOKEN>
{"leagues":["basketball/nba","american_football/nfl"],"maxEvents":10}
