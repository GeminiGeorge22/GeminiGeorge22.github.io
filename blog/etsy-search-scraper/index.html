Scrape Etsy search results with sort + price filters

2026-10-03 (America/Toronto). Actor build 0.2.3.

Disclosure: I publish and maintain the Actor this tutorial uses (publicrecords/etsy-search-scraper on Apify).

You have a search query and you need structured listing rows you can filter by price and sort the way Etsy’s own menu does — not a screenshot of page one.

The method

  1. Run on Apify residential proxy (default). Passthrough — Apify bills proxy usage; our PPE has no proxy markup. A blocked page charges no listing rows.
  2. Set sort + price filters with the real input fields. sort is one of relevance, newest, price_asc, price_desc, top_reviews. minPrice / maxPrice are whole currency units.
  3. Cap the run with maxItems and/or maxPages.
  4. Bill only delivered complete rows. PPE: actor-start $0.005 once + listing-row $0.006 each. Never quote listing-row-bulk $0.004.
  5. Join to shop velocity when you care about the seller. Companion Actor publicrecords/etsy-shop-velocity.
