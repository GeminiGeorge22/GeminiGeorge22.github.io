Scrape Etsy search results into listing rows

2026-10-02

Disclosure: I publish and maintain the Actor this tutorial uses (publicrecords/etsy-search-scraper on Apify).

You have a search query — a niche keyword, a product type, a competitor phrase — and you need structured listing rows (title, price, shop, badges), not a screenshot of page one. Opening tabs by hand does not leave a dataset you can filter, score, or join to a shop tracker.

The method

  1. Run on Apify residential proxy (default). Search HTML is challenged often; plain datacenter egress from Apify cloud commonly fails. The Actor defaults to Apify Proxy RESIDENTIAL (billed by Apify as proxy usage — no markup on our PPE). You can also plug in your own residential proxy. If every page is challenged, the Actor exits blocked_on_your_proxy and charges no listing rows for those pages.
  2. Parse listing cards into one row per listing. Fields include listing_id, url, title, price, currency, shop_name / shop_url, rating / review counts, and badges (bestseller, popular_now, free_shipping, etc.), plus page, position, and query.
  3. Paginate under a hard cap. Set maxPages (and optionally maxItems) so a warm hang cannot run forever. Incomplete cards (missing price/title/shop) are pushed free and never billed.
  4. Bill only delivered complete rows. PPE is actor-start once + listing-row per complete listing. Blocked pages charge nothing. Proxy usage is Apify’s bill, separate from our event prices.
  5. Join to shop velocity when you care about the seller, not only the card. Listing rows give you the shop name; the companion Actor publicrecords/etsy-shop-velocity turns shop names into sales counters and rates (no proxy on that path).

Doing it for real (measured run)

Etsy Search Scraper (publicrecords/etsy-search-scraper) returns one dataset row per listing card from public Etsy search HTML. It works out of the box on Apify residential proxy (passthrough — Apify bills proxy usage to your account; our PPE is only actor-start + listing-row). Or plug in your own residential proxy if you prefer.

When a page is challenged (measured)

An earlier attempt with the same input (9RfVZjBbBvCvbs8JX) ended after ~620 s with blocked_on_your_proxy — every page challenged on that proxy path, so zero listing-row charges. Retry on Apify RESIDENTIAL US (pRpdAMmfeMHdmuRXA) succeeded in ~53 s with 36 complete rows. Occasional challenges and a retry are normal; prefer the default RESIDENTIAL group, and you only pay listing-row for rows actually delivered.

Cost math you can recompute

  • 1 complete listing row: $0.005 + $0.006 = $0.011
  • 36 rows (this tutorial): $0.005 + 36×$0.006 = $0.221
