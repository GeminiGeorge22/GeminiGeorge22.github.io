How to turn a web page URL into LLM-ready Markdown

A short path for RAG and agent builders who need readable text from a list of pages, without launching a browser. Author: Public Records (I maintain the Actor).

Open the Actor on Apify →

What you get

The Web Page to Markdown Actor takes page URLs and returns clean Markdown plus title, description, language and canonical URL when the page has them. It uses plain HTTP (no browser). It is not a site crawler: you choose the URLs. If a page only fills in after JavaScript runs, use JavaScript Page to Markdown instead.

1. Run the Store example

On the Store page, keep the example input and start a run on your Apify account. The free tier is enough to try it. Pay per page after that; current rates are on the Store page.

2. Or pin it in MCP

Paste https://mcp.apify.com?tools=publicrecords/url-to-markdown into Claude, Cursor, or another MCP client and sign in with your own Apify account.

3. Or schedule it in n8n or Make

Import templates/n8n/url-to-markdown.json and add a Header Auth credential Authorization: Bearer <APIFY_TOKEN>. The Make HTTP recipe is in templates/make.

POST https://api.apify.com/v2/acts/publicrecords~url-to-markdown/run-sync-get-dataset-items
Authorization: Bearer <APIFY_TOKEN>
{"urls":["https://quotes.toscrape.com/"]}
