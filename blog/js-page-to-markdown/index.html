How to render a JavaScript page to Markdown

A short path when a plain HTTP fetch comes back empty: React, Vue, Angular and other pages that fill in with JavaScript. Author: Public Records (I maintain the Actor).

Open the Actor on Apify →

What you get

The JavaScript Page to Markdown Actor opens each URL in Chromium, lets the page's JavaScript run, and returns clean Markdown. Turn on screenshots for a PNG or JPEG of each page. If the text is already in the HTML, the cheaper Web Page to Markdown Actor is usually enough.

1. Run the Store example

On the Store page, keep the example input (screenshots off) and start a run on your Apify account. The free tier is enough to try it. Pay per page after that; current rates are on the Store page.

2. Or pin it in MCP

Paste https://mcp.apify.com?tools=publicrecords/js-page-to-markdown into Claude, Cursor, or another MCP client and sign in with your own Apify account.

3. Or schedule it in n8n or Make

Import templates/n8n/js-page-to-markdown.json and add a Header Auth credential Authorization: Bearer <APIFY_TOKEN>. The Make HTTP recipe is in templates/make.

POST https://api.apify.com/v2/acts/publicrecords~js-page-to-markdown/run-sync-get-dataset-items
Authorization: Bearer <APIFY_TOKEN>
