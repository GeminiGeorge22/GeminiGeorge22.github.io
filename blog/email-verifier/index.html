How to check email domains, MX records and disposable addresses (not the mailbox)

A short path for cleaning a list before a send, or scoring leads, without sending mail or probing mailboxes. This is not a mailbox verifier and it does not do an SMTP check. Author: Public Records (I maintain the Actor).

Open the Actor on Apify →

What you get

The Email Verifier takes a list of addresses and returns a verdict for each one: syntax, whether the domain exists, MX records, disposable domains, role accounts, SPF/DMARC and typo suggestions. It does not check the mailbox and it does not send mail. A deliverable_domain verdict only means the domain and its MX records can receive mail; a made-up name at a real domain can still get that verdict.

1. Run the Store example

On the Store page, keep the example input and start a run on your Apify account. No mail is sent. The free tier is enough to try it. Pay per checked email after that; current rates are on the Store page.

2. Or pin it in MCP

Paste https://mcp.apify.com?tools=publicrecords/email-verifier into Claude, Cursor, or another MCP client and sign in with your own Apify account.

3. Or schedule it in n8n or Make

Import templates/n8n/email-verifier.json and add a Header Auth credential Authorization: Bearer <APIFY_TOKEN>. The Make HTTP recipe is in templates/make.
