Pin six live Actors for agents — Crosswalk (verified org socials) first, then official TED / USASpending / Grants.gov / UK Find a Tender / Legistar. No Actor source in this hub; manifests only.

1. Copy this remote URL

https://mcp.apify.com?tools=publicrecords/company-social-profile-finder,publicrecords/eu-ted-notices-scraper,publicrecords/usaspending-awards-scraper,publicrecords/grants-gov-scraper,publicrecords/uk-find-a-tender-scraper,publicrecords/legistar-meetings-scraper
Open on Apify MCP

2. Cursor

Settings → MCP → Add server → paste the URL above, or merge:

{
  "mcpServers": {
    "publicrecords": {
      "url": "https://mcp.apify.com?tools=publicrecords/company-social-profile-finder,publicrecords/eu-ted-notices-scraper,publicrecords/usaspending-awards-scraper,publicrecords/grants-gov-scraper,publicrecords/uk-find-a-tender-scraper,publicrecords/legistar-meetings-scraper"
    }
  }
}

3. Claude / Claude Desktop

Add the same mcpServers.publicrecords block to your Claude Desktop MCP config, or use the dialect file:

  • cursor-rules.mdc
