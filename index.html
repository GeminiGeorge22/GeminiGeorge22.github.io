Actors by publicrecords

Publisher docs for live Apify Actors. Flagship: Etsy Search Scraper and Etsy Shop Sales Tracker (plus the Etsy Search & Shop Sales MCP). Also company socials (Crosswalk), official public-records APIs, and ATS job feeds. Store listings stay on apify.com; this site is for search, agents, and inbound authority.

Flagship — Etsy search and shop sales

  • Etsy Search Scraper — Live Etsy search as listing rows (title, price, shop, badges, rank). Keyword, market, or category. Apify residential by default.
  • Etsy Shop Sales Tracker & Scraper — Daily sales counters, 7-/28-day changes, modelled rates and breakout flags. One row per shop; no proxy on the panel path.
  • Etsy Search & Shop Sales MCP (v1.0.1) — Manifest-only pin for both Actors via Apify MCP.

Company socials

  • Company Socials (Crosswalk) — Find a company's LinkedIn, Instagram, Facebook, X, TikTok and YouTube from its website or name. Platform-checked links carry confidence and evidence; organizations only, never people.

US federal and municipal

  • Federal Opportunity Feed — SAM.gov + Grants.gov fused, deduped, agency-normalized, with USASpending category leaders and monitor deltas. No SAM.gov key on the bulk path.
  • USAspending Awards — Federal contract and IDV awards from the official USASpending.gov v2 API (plain awards pull).
  • Grants.gov Finder — Open FOAs from the official Grants.gov search2 API to flat JSON.
  • City Council Minutes (Legistar) — Public meetings, agendas, minutes links, and legislation via the official Legistar Web API.

EU and UK procurement

  • EU TED Tenders — Official TED Search API v3 notices to flat JSON. Anonymous search, no API key.
  • UK Find a Tender — Above-threshold notices via the official OCDS 1.1 API.

Jobs and hiring signals

  • Greenhouse Jobs Scraper — New Postings Since Any Date — Greenhouse job-board API postings with metadata, URLs, timestamps and optional descriptions.
  • Lever Jobs Scraper — New Postings Since Any Date — Lever job-board API postings with metadata, URLs, timestamps and optional descriptions.
  • Ashby Jobs Scraper — New Postings Since Any Date — Ashby job-board API postings with metadata, URLs, timestamps and optional descriptions.
  • SmartRecruiters Jobs Scraper — New Postings Since Any Date — SmartRecruiters job-board API postings with metadata, URLs, timestamps and optional descriptions.
