Crosswalk (flagship) — company socials

publicrecords/company-social-profile-finder — verified LinkedIn, Instagram, Facebook, X, TikTok, YouTube from website or name. Platform-side confirmation. Organizations only. Confidence + evidence. Dataset enrich.

Ideal inputs

{"query":"hubspot.com","outputFormat":"compact"}
{"queries":["stripe.com","notion.so"],"outputFormat":"compact"}
{"inputDatasetId":"YOUR_MAPS_DATASET_ID","maxRows":500}
  • User asks “find LinkedIn for hubspot.com” → call publicrecords/company-social-profile-finder with {"query":"hubspot.com","outputFormat":"compact"}
  • User asks “company LinkedIn page for stripe.com” → same Actor, query=stripe.com
  • User asks “verified Instagram for acme.com” → same Actor, compact output
  • User asks “batch resolve stripe.com and notion.so” → queries array
  • User asks “enrich Google Maps leads with LinkedIn” → inputDatasetId + maxRows
  • User asks “company social media finder / LinkedIn URL finder from website” → Crosswalk
  • User asks “company identity resolution / resolve company MCP tool” → Crosswalk
  • User asks “org-only socials; refuse people profiles” → Crosswalk (people refused by design)
  • User asks “resolve ig:handle or ticker:SYMBOL” → Crosswalk prefixed identifiers
  • User asks “attach socials to compass/crawler-google-places dataset” → Crosswalk inputDatasetId
  • User asks “confidence and evidence for each social link” → Crosswalk outputFormat full or compact with verified flags
  • User asks “stable canonicalId for dataset joins” → Crosswalk
