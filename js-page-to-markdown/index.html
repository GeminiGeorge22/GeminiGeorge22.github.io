JavaScript Page to Markdown: Render JS Web Pages + Screenshot

Opens each URL in a real Chromium browser, lets the page's JavaScript run, and returns the rendered page as clean Markdown. Turn on screenshots for a PNG or JPEG of every page too.

Open JavaScript Page to Markdown on Apify →

The one question it answers

What text does a person actually see on this JavaScript page, as clean Markdown — and, optionally, what does a screenshot of the page look like?

Who it is for

AI agent and RAG builders who need the text a person sees on a React, Vue, Angular, Svelte or Next.js page; developers who do not want to run their own headless browser; analysts and SEO teams who want page text, metadata and a screenshot in one run.

Input

FieldWhat to putDefault
urlsPages to render (up to 500 per run).Store example: quotes.toscrape.com/js/ and react.dev
waitForSelectorWait for late-loading content, e.g. .product-listempty
scrollToBottomScroll first so infinite-scroll items are includedfalse
screenshotSave a PNG or JPEG of each page to the run's key-value storefalse

Output

One dataset row per rendered page, with markdown, metadata, a token estimate, and optional screenshotUrl. No outside AI API is used. Pay per event on your own Apify account (free tier available). Current rates are on the Store page. Pages that fail, time out or are skipped are not charged per page.

If the page's text is already in its HTML, the cheaper and faster Web Page to Markdown Actor is usually enough. Public pages only; login, paywall and CAPTCHA pages are not supported. Example links on the Store page are not an affiliation with those sites.
