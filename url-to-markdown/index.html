Web Page to Markdown: URL to LLM-Ready Text

Give it web page URLs and get back clean Markdown for each page, ready for an LLM, a RAG index or an AI agent. It fetches pages over plain HTTP with no browser, so it is fast and cheap. It is a single-page tool, not a site crawler.

Open Web Page to Markdown on Apify →

The one question it answers

What is the clean, LLM-ready Markdown of these web page URLs, with title, description, language and canonical URL when the page has them?

Who it is for

Developers building RAG and AI-agent pipelines, and anyone who needs readable text from a list of pages.

Input

FieldWhat to putDefault
urlsWeb pages to convert, one per line (up to 1,000 per run).Store example: a Wikipedia article and quotes.toscrape.com
contentScopemain (recommended) or fullmain
cssSelectorKeep only matching elements, e.g. articleempty
maxCharsCut very long pages; the row then says truncated: true200,000

Output

One dataset row per page, with markdown, metadata, a token estimate, and needsJavaScript when the static HTML may be incomplete. Pay per event on your own Apify account (free tier available). Current rates are on the Store page. No browser is launched.

This is not a site crawler, and it does not render JavaScript. For React, Vue, Angular or other pages that only fill in after JavaScript runs, use the JavaScript Page to Markdown Actor. For PDF or Word files, use the PDF to Text & Markdown Extractor. Example links on the Store page are not an affiliation with Wikipedia or quotes.toscrape.com.
