Sports Odds API — BetRivers, Unibet, Paf, Svenska Spel

Live and pre-game sports odds from BetRivers (12 US states + Ontario), Unibet (7 countries), Paf, Svenska Spel and ATG, in one call. One row per game, with every book's price and the best price per outcome. No API key. Pay per game.

Open Sports Odds API on Apify →

The one question it answers

What are the live and pre-game odds, across BetRivers, Unibet, Paf, Svenska Spel and ATG, for these games — and what is the best price per outcome?

Who it is for

Sports bettors and developers who need a sports odds API for Kambi-powered books. It is not a DraftKings or FanDuel feed.

Output

One dataset row per game, with each book's price and the best price per outcome. Pay per game. No separate odds-API key — you run it on your own Apify account (free tier available).

Try it in 1 minute

  1. Open the Store page and use the example input (NBA, NFL, NHL, MLB, Premier League; max 10 events).
