n8n templates

Import these workflow JSON files into n8n (Workflow menu → Import). Set YOUR_APIFY_TOKEN in the HTTP Request Authorization header — never commit a real token. Each workflow: Schedule → run Actor via Apify API → fetch dataset items. Tune the input JSON to your filters.

  • Etsy Search Scraper — search listings (flagship)
  • Etsy Shop Sales Tracker — daily counters
  • Sports Odds API — BetRivers, Unibet, Paf, Svenska Spel, ATG
  • Spotify Play Count Scraper — play counts and monthly listeners
  • Crosswalk — enrich Maps / lead dataset (flagship)
  • EU TED Notices — daily pull
  • USASpending Awards — daily pull
  • Grants.gov Opportunities — daily pull
  • UK Find a Tender — daily pull
  • Legistar Meetings — daily pull

Make HTTP recipes (import or rebuild from the JSON) live in publicrecords-mcp/templates/make. Official Make / Zapier galleries stay pending (partner / account gates). Use these files and your own Apify token.
